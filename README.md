## 👤 About Me

I am a Product Manager with 3 years of cross-industry experience. I have worked in automotive import and channel sales, then gaming hardware, and now software at a font technology company.
My way of working starts with user interviews to find the real problem. Then I write the PRD, API specs, and system architecture myself. Then I use AI coding agents (Claude Code, Codex) to build a prototype and a working version, hand it to the RD team for code review, and ship it. 
In the past year I delivered a font showcase website, a font e-commerce platform, and two internal production tools this way. I also built an AI tool governance process and a shared Skill Repo for my department.
I believe a PM's value is not in passing requirements down the line. It is in turning a vague problem into a clear spec, and translating user needs into technical requirements a team can actually execute. 
This profile is where I keep the actual work: architecture diagrams, API documents, and notes on how I made decisions
